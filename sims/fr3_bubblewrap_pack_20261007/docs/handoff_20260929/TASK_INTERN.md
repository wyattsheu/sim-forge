# 任務說明

逆物流 Demo:雙臂打開紙箱 → 掀開泡泡紙 → 夾出馬克杯。
你負責**包材(泡泡紙)**,外加把**紙箱蓋降伏影片**重做。

## 方位(全部吃箱子自己的座標)

```
前 = +y     後 = −y     右 = +x     左 = −x     上 = +z
```

| | |
|---|---|
| 紙箱 | 外徑 270(x) × 230(y) × 131(z),內腔 264 × 224。**長邊 270 沿 x,也就是落在左右方向** |
| 上蓋 ×2 | 在 ±y = **前 / 後**,是**外層**,開箱時先開 |
| 下蓋 ×2 | 在 ±x = **左 / 右**,是**內層**,開箱時後開 |
| 杯子 | 橫放在箱子正中央,**杯口朝前(+y)、杯耳朝右(+x)** |
| 包材 | 折序必須讓**前後在外層**,才能照 PPT 先開前後、再開左右 |

細節(鉸鏈高度、牆頂、板厚、dynamic)在 `ORIENTATION_AND_SIZE.md`。

---

## 流程

包裹是用**模擬折疊**建立的。這樣做的理由是:目前想不到別的方法,
能一邊把包裹做出來、一邊向大家說明它是對的。可能有其他做法,但先以這個為準 ——
**想到別的做法可以跟我說。**

```
攤平的布 → 四折包住杯子 → 六面壓實 → 放進紙箱 → 關上四片蓋
                                                  開箱就是反過來
```

現在的做法是在布的整條外緣建錨點、用 attachment 綁住布,把錨點沿弧線拉到杯子上方,
布被拖著走,折痕是物理自己出來的。前一折留在原地,下一折蓋上去。

---

## 要達成的目標

1. **包裹真的待在紙箱裡** —— 布跑出內腔的頂點數 0,杯子橫放在中央
2. **包材要能被分四步掀開** —— PPT 是前後先打開、左右後打開,所以外層必須是前後
3. **一支流程影片** —— 讓大家看得到這個模型目前在理論上是對的
4. **一支搬箱子的影片** —— 把紙箱移動,確認包裹留在箱內,不會因為穿模掉出去
5. **把包材壓得更小** —— 見下面那一節,這也是任務之一
6. **降伏影片看得懂** —— 能一眼說出「壓到 X 度 → 放開 → 回彈到 Y 度並停住」,Y 明顯不等於起點

## 包材壓得不夠小

布用的是 Isaac Sim 的 **surface deformable** —— 理論上它是一張零厚度的膜,
壓實之後高度應該接近「杯子 + 幾層薄膜」,不該卡在現在這個高度。

量過的兩件事,可以當起點:

- 層與層之間實際分開大約 3mm
- 把 `surfaceThickness` 從 10mm 改成 4mm,**層間距沒有變** ——
  所以撐開層與層的不是 surfaceThickness,要往別處找

可以看的旋鈕(還沒一個一個試過):

| | |
|---|---|
| collider 的 `contactOffset` / `restOffset` | 層間那 3mm 比較可能來自這裡 |
| self-collision 相關參數 | 布對布的接觸怎麼算 |
| solver position iterations | 太低會壓不住、會塌陷或穿透 |
| `--bend` 彎曲勁度 | 太硬就折不貼,折痕附近會鼓起來 |
| `--layer_mm` | 折疊終點的 z 分層,本身就在刻意製造高度 |
| `--young` / `--thick` | 材料本身 |

另外高度 = 層數 × 層間距。層數由布的大小決定,那是另一個方向。
