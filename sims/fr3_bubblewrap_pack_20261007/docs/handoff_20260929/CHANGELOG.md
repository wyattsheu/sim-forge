## 2026-09-27 — 目前這包

### 紙箱 `carton_w131.usd`(取代 `carton_flush.usd`)

| 項目 | 舊 | 新 |
|---|---|---|
| 上蓋半寬 | 117.3 mm(每邊留縫 14.7) | **131.0 mm(每邊留縫 1.0)** |
| ±x 牆頂 | 130.0(四面等高) | **120.0 = 下鉸鏈 − 2t** |
| ±y 牆頂 | 130.0 | **126.5 = 上鉸鏈 − 2t** |
| 下鉸鏈 / 上鉸鏈 | 122.0 / 128.5 | **123.0 / 129.5** |
| 箱高參數 | 130 | **131** |

**為什麼改牆高**:鉸鏈放在箱壁內面,但蓋子是 2t = 3mm 厚的板。蓋子一旦傾斜,
外上角就掃進箱壁那 3mm 的帶子,而且此時還在箱口以下。

**為什麼鉸鏈抬 1mm**:牆頂必須降到「鉸鏈 − 2t」才 0 重疊,但原本的鉸鏈 122 會讓
±x 牆頂降到 119mm —— 低於包裹高度 120mm,包裹會從側面露出。鉸鏈整組抬 1mm 解決。
**箱高因此從 130 變 131,偏離 PPT 規格 1mm。**

**驗證**:`scripts/carton_sweep.py`(純 CPU,0~180° 每 0.5° 一格)

```
                    舊箱 carton_flush        新箱 carton_w131
下蓋 fxp vs ±x 牆   360/361,最深 1.50 mm    0/361,0.00 mm  ✅
上蓋 fyp vs ±y 牆   360/361,最深 1.50 mm    0/361,0.00 mm  ✅
```

舊箱留在 `carton/superseded/`。**拿同一支工具跑舊箱會報出 720 個重疊角度** ——
這是工具有效性的證明(只會印 PASS 的檢查沒有價值)。

### `wrap_sim.py` — 入箱改成整包剛性搬移

**問題**:入箱時只把布搬到 bbox 置中,杯子沒跟著搬;而且杯子還被 `MZ` 公式另外加了
`CDZ`、又被硬拉回 (0,0) —— 但壓實後杯子已漂到 (−8.79, −5.48),等於憑空跳了 10mm。
三個軸都錯開。

**驗證**:`scripts/chain_pen.py`(邊級別,每條邊取 19 個內點)。同樣吃 `packed_pressed.npz`:

```
            t=0   2.5   5.0   7.5  10.0  12.5  15.0
修復前  33    6     5     4     4     4     4   (1.4 mm)
修復後  45    8     0     0     0     0     0   (0.0 mm)
```

判斷依據不只是數字變小 —— 是**階躍**:折疊、壓實全程 0,入箱第一格突然跳 +172 再衰減。
階躍 = 擺位/記帳問題;漸增 = 真的被物理擠出來。

## 這包**沒有**包含的東西

- **箱內繃緊拉(`--taut`)** —— 2026-09-28 加的功能,把逆向攤開之後的動作從
  「搬出箱子攤地上」改成「箱內四邊拉到杯子快被帶起來」。**第一次測試無效**
  (杯子從 kinematic 放開的瞬間會彈 6mm,誤觸發臨界偵測),還在修。
- **volume deformable 版**(泡棉殼提杯)—— 跑出跟隨比 0.664,還沒收尾。
- `scene_fixed.usd` 的定裝照 —— `shot_full.py` 對這個場景會 segfault。
