## 4. 哪個方案值得採用

**沒有。** 判準(他片 <5% 且 yn 越線 ≥80%、放手後 ≥50%)無一組達成:
- 唯一 <5% 的數字(C1 yp 2.8%、f0.2 yp 放手後 3.0%、p50 yn「扣釘住」0.0%)都伴隨越線 ≤64%、放手後 ≤11%,或根本是守衛放手後的殘影。
- 方案 A 證實 PhysX 不支援有限剛度;代理落後 ≤1 mm 表示 fmax 0.2~1 N 根本沒限到力,要有感得降到 ~0.05 N 以下,但那時 yn 自己也掀不起來。
- 方案 B 的 attach 釘法立刻把邊長比拉到 5 觸發守衛;且三組都是錯的片尺寸(400 mm),**需用 500 mm 重跑才算測過**。
- 方案 C 說明他片拖動不是綁到被壓頂點造成的(遮罩排除 0 點),是 yn 中段翻起時透過接觸摩擦帶動 xp/xn/yp。
- 另一個干擾:run-to-run 變異很大(C2 = 基準重跑,他片 20→11.5%),單組比較無法分辨 ±8 個百分點內的差異。

建議旗標組合:維持基準(見 §0),不加 `--attach_proxy / --hold_others / --attach_mask_own / --lift_first_mm / --attach_layer top`。
