# arm ↔ wrap_vol 介面需求(2026-10-07)

手臂端:`arm/peel_traj_v2.py`(6 軸 follower 雙臂,Lula IK,URDF 由 `robot_model.py` 從場景 USD 產生)。
包材端:`vol/wrap_vol.py`(volume deformable)。本文件只規定兩邊交換的量與座標;手臂端不改 `vol/`。

## 1. 座標系

| 名稱 | 定義 |
|---|---|
| 箱局部 L | 定版紙箱 `carton.usd` 的座標:原點 = 箱底外面中心,z 向上;270 mm 長邊沿 +x;內腔 \|x\| ≤ 132、\|y\| ≤ 112 mm;箱底內面 z = 3;±x 牆頂 120、±y 牆頂 126.5;鉸鏈 下層(fx)z 123、上層(fy)z 129.5 |
| vol 世界 V | `wrap_vol` 模擬的世界;箱局部 = V − OFF,OFF = (0, 0.200, 0.097) m(目前值,見 `vol/soft/s2/wrap_vol.log`;改了要一起輸出) |
| 場景世界 S | `scene_final.usd` / 雙臂場景的世界;桌面 z = 20 mm;左臂基座 (−20, +457.5, 39.1) mm、右臂 (−20, −457.5, 39.1) mm |

L → S:`p_S = T + Rz(yaw) · p_L`,T = (−20, 0, 20) mm。
- `scene_final.usd` 原值 yaw = 90°:`x_S = −20 − y_L`、`y_S = x_L`、`z_S = 20 + z_L`
- **定案擺法 yaw = 270°**(= 原值再轉 180°,`peel_traj_v2.py --yaw_extra 180`):`x_S = −20 + y_L`、`y_S = −x_L`、`z_S = 20 + z_L`
  - 例:抓取點 #1 L (112.9, −6.9, 123.6) → S (−26.9, −112.9, 143.6) mm(右手側)
  - 上蓋 fyp → 世界後方 (+x)、fyn → 前方 (−x);下蓋 fxp → 右手側 (−y)、fxn → 左手側 (+y)
- 方向向量只乘 Rz(yaw),不加 T。

**約定:wrap_vol 輸出一律用箱局部 L(mm 或 m 註明),手臂端自己轉 S。**

## 4. 已知限制

- 夾指單指外框 36 × 70 × 60 mm:抓點離牆 < ~30 mm 時,指頭的 60 mm 寬會碰牆或已開的蓋(#1 離 +x 牆 19 mm,在下蓋平躺 180° 時腕部會撞到;下蓋垂到 260° 才無碰撞)。
- 上蓋開蓋:手只能做 35° → 50°(前 0 → 35° 由 kinematic 直接轉,代表摺痕預彎/指甲勾起;50° → 180° 也是 kinematic 接續)。
