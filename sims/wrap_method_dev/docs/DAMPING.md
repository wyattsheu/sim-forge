# Volume 布阻尼掃描(2026-10-14)

結論:edamp 0.02–0.05 能把折疊停留期間的顫抖壓掉約 40–55%(高頻成分壓掉 50–64%),但兩組完整鏈的抓取段都比 out_ga3 差很多,所以**完整鏈維持 0/0,不建議加阻尼**。ldamp 對顫抖幾乎沒幫助。edamp ≥ 0.2 時布跟不上錨點,0.5 以上就折不上去。

兩組加了阻尼的完整鏈抓取段都明顯變差。各只跑了一次,無法分辨這是阻尼本身造成,還是改了初始條件後混沌發散。

## 建議
- 抓取完整鏈:維持 `--ldamp 0 --edamp 0`。
- 只做折疊或入箱的展示影片:`--edamp 0.02`。顫抖降 40%,自穿 0,邊長比最接近 base;0.05 顫抖最低,但邊長比 min 0.169。
- 不用 ldamp(靜置段的顫抖反而變大),也不要讓 edamp ≥ 0.2。
