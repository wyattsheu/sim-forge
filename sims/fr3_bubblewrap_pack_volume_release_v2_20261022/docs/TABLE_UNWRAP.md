# TABLE_UNWRAP:包裹先拿出箱子、放在桌面上再掀(2026-10-21)

目標:驗證「整包拿出箱子放到桌面上之後再掀」時,yn 片放手後能不能自己攤開、不彈回。
背景是 PGRASP.md / MATSWEEP.md 的結論:在箱內掀,片根部很深,片質心過不了箱壁,放手後一定倒回箱內。真人拆包也是先把包裹拿出來再拆。

## 結論
**可以。包裹放在桌面上掀,yn 片放手後 10 s 會平躺在桌面上、不彈回。綁定版 3/3、寬指純摩擦版 3/3、yp 第二片 1/1 都達標。**
判準是放手後 10 s 翻片角 < 45° 且越線 ≥ 80%。實測放手後 10 s 翻片角 0~4°,越線 100%,片質心在鉸線外 81~85 mm,只比桌面高 1~2 mm。
兩片都攤開以後,杯頂覆蓋從 100% 降到 71%,也就是露出 29%;還蓋在杯上的是 xp / xn 兩片。

另外有三件要先知道的事:
1. **「不入箱」時如果照舊放掉全部錨點,整包會在 1.5 s 內自己彈開攤平,杯子也會被翻正**(`table/notape`)。布的 rest 形狀是平板,之前能保持包好,是靠紙箱和蓋子壓住。所以桌面模式預設用 `--ut_tape 1`:錨點不移除,當成封箱膠帶;要掀哪一片,就在那一片夾好的同時移除那一片的錨點。
2. **讓片翻回去的是材料記憶,不是幾何。** 塑性對照 `table/P` 用 `--plastic_on_fold 1`(放錨點前把整張布的 rest 改成折好的形狀,不用膠帶,只跑 1 次):片放手前大致攤平(翻片角 16°、越線 99%),放手後卻翻回去,0.5 / 2 / 10 s 的翻片角是 46° / 81° / 138°。如果真實的泡泡布有折痕記憶,放在桌面上也會翻回。不過這一次的夾持很差(重夾 2 次、只綁到 2 點、他片 99% 都被帶動),只能當成定性結果。
3. 杯子被推動主要發生在挑角和合指階段,不是掀開階段。夾好時杯已經位移 12~36 mm,放手後 10 s 是 13~39 mm,掀開這一段只多了 0~4 mm。原因是桌面上沒有箱壁擋住杯子,而杯子已經轉成 dynamic,下指插到布下時會把整包推走。他片被帶動 18~45%,大多是 xp / xn 靠 yn 側的耳角(flat y < −71.5 的部分),yn 攤開時被一起帶出來。

欄位定義(`wrap_vol.py` 的 `ut_stat` / `ut_log`):
- **翻片角**:片的「外段方向」角度。把主片(|flat x| < CX,不含耳角)在 flat 座標上離折線 50~70% 的那一帶,和 85~100%(尖端)的那一帶各取中面質心,兩點連線在 (往外, z) 平面上的角度就是翻片角。0° = 平躺往外,90° = 直立,180° = 蓋回杯頂。另外記錄「質心角」= 鉸點到片質心的方向。
- **鉸點**:夾點那一欄,從折線往外走,最後一個仍貼著桌面(z < 桌面 + T + 3 mm)的頂點。**材料長 L** = 鉸點到夾持頂點(flat 中位)的距離。
- **越線**:規劃時在折線內側(蓋在杯頂上那段)的頂點,有多少比例越過了名義折線 |y| = 71.5 mm(定義同 MATSWEEP)。**質心往外 / 高**:主片中面質心相對鉸線(往外為正)和相對桌面 + T/2 的高度。
- 他片、杯位移的基準都是該片開始規劃的那一刻。「夾好時」= 開始抬起前最後一筆量測。穿杯分成夾取段(合指時下指把布壓進杯,沿用舊行為)和從抬起開始之後,後者全部是 0。
- 寬指版的「指間頂點」= 合指後兩指之間的布頂點數,「掀中指間 min」= 從抬起到放手期間的最小值。3 次都沒有掉布,最少還有 32~34 點。

## 怎麼做的(`--unwrap_on_table 1`)
- **不入箱**:四折加收耳(側板照舊收到內腔 −3 mm,包形和入箱版相同)以後,箱子留在旁邊 OFF_SIDE,地面就是桌面(碰撞保留)。原本的入箱、關蓋那段時間照舊空跑,側板在 T_REL 撤走;T_ANC 時杯子轉 dynamic。錨點在 `--ut_tape 1` 下保留。接著 settle `--ut_settle_s`(2 s)就開始掀,搬箱和開蓋都不做(T_END_ALL = T_ANC + 2)。局部座標框和入箱版一樣(桌面 z = CDZ),箱壁從抓點排名和候選篩選裡拿掉(IX = IY = 1 m)。
- **夾**:流程和舊版完全相同(挑角、下指、上指合、綁定或純摩擦)。夾好的那一刻移除該片的錨點(剪膠帶)。
- **掀**(取代越壁弧線):
  1. 先垂直抬起 `--ut_lift_mm` 40 mm,用 1 s。
  2. 繞桌面鉸點 (y_h, 桌面 + T/2) 走弧線:角度從起始的約 111~117° 線性轉到終點的約 1°;半徑在前 30% 從 r0 變到 `--ut_arc_k` × L(0.9 L),中段保持,最後 25% 再變到終點半徑。
  3. 夾爪同時繞 x 軸轉 180°,終點姿態修正到 u 朝外、n 朝下。
  4. 終點夾爪中心在鉸點往外 `--ut_end_k` × L(1.0 L)、z = 桌面 + T 的位置。弧線用 `--peel_t` 8 s。
- **放手**:停 2 s 後,兩指沿 n 張開 10 mm(翻面後原本的上指在布下、進到桌面下),再沿 u 往外抽「指深 + 20 mm」,最後抬 80 mm。放手後觀察 10 s(`--grasp_tail_s 8.5`),在 0.5 / 2 / 10 s 印出 `[table]` 量測。

## 旗標(預設 = 舊行為;`wrap_vol.py` 備份 `wrap_vol.py.before_table`,+106 / −4 行,都標了 `[table]`)
| 旗標 | 預設 | 說明 |
|---|---|---|
| `--unwrap_on_table` | 0 | 1 = 不入箱、在桌面上掀(會強制 `--extract 0`)。加上 `--until fold` 也會接著跑掀開段 |
| `--ut_tape` | 1 | 錨點當膠帶保留,掀哪片就在夾好時移除哪片的錨點;0 = 放錨點時全部移除(整包會自己彈開) |
| `--ut_settle_s` | 2.0 | 放錨點後停幾秒才開始掀 |
| `--ut_lift_mm` / `--ut_lift_t` | 40 / 1.0 | 夾好後垂直抬起的高度 / 用時 |
| `--ut_arc_k` | 0.9 | 弧半徑 = 這個 × 材料長 |
| `--ut_end_k` | 1.0 | 終點離鉸點往外 = 這個 × 材料長,z = 桌面 + T |

沒做的部分:「入箱、關蓋、搬箱以後,用 kinematic 把整包抬出來」這一版沒做。杯子轉成 kinematic 抬起時,布不會跟著走,一定要另外綁住或用夾爪抱住整包,所以照任務的建議先做簡單版。

## 重現
```
cd vol
table/run.sh B attach                         # 綁定版 3 次(run3.sh,MAXPAR 預設 2)
table/run.sh W wide                           # 寬指純摩擦 3 次
N=1 table/run.sh Y attach --second 1          # yp 第二片
N=1 table/run.sh P attach --plastic_on_fold 1 --ut_tape 0    # 塑性對照(材料記憶)
N=1 table/run.sh notape attach --ut_tape 0    # 錨點全放(整包自己攤開;實際存檔是當初的 smoke 跑,CMD 裡的路徑是 table/smoke)
python3 table/table.py table/B table/W table/Y table/P table/notape
table/cut_short.sh table/W/2/wrap.mp4 videos/DEMO_unwrap_table_short.mp4
```
`table/run.sh` = run3.sh `@demo`,再加上 `--hand2 off --hand2_keep 0 --hold_yp 0 --extract 0 --second 0 --quality fast --edamp 0 --guard_yn 3.5 --guard_n 2 --peel_t 8 --hand1_jaw 1 --jaw_collide 1 --release_watch 1 --grasp_tail_s 8.5 --until fold --unwrap_on_table 1`。
`wide` 再加上 `--grasp_attach 0 --pick_mode wide --wide_mm 150 --wide_squeeze_mm 1.0 --wide_depth_mm 40 --pick_in_mm 45 --ffric 2.0 --chord 1 --clear_mm 2 --pick_mm 0`(和 PGRASP.md 相同)。
一次 fast 約 4.5~5 分鐘(Y 兩片 7 分鐘)。
