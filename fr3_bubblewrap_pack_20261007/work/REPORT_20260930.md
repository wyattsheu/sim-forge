## 1. 結論(先講)

1. **包裹疊很高的根因是錨點幾何,不是碰撞參數。** 每一折的尖端被無窮硬的 attachment 釘在 `杯頂 + 12mm + 第幾折 × layer_mm`(四折 +12/+20/+28/+36),而且被認為放不掉;第二段再用 100 個 hold 錨把前兩折釘死;壓實段還建 4 個錨把四邊中點釘在起始高度。布是被吊著,不是疊著。
2. **attachment 其實可以在模擬中放掉**(`stage.RemovePrim(Scope)` / `attachmentEnabled=False` / `SetActive(False)`,當步生效,鄰近錨點不受影響)。原作者 09-25「改了無效」的結論是探針裡三個同邊錨點一起升、被鄰居撐住的量測假象。`probe_detach.py` 7 種做法逐一實測。
3. **縮 contactOffset / restOffset、加解算迭代、降 bend,都不是答案。** contactOffset 5→2mm 讓層直接互穿(自穿模 13 → 400~3700);只縮 restOffset 層間距減半但自穿模翻倍、且出生時就多 200 次;bend 4→1 回彈反而更大;solver 128 + 碰撞迭代 ×2 救不回互穿。surfaceThickness 10→4 對層間距完全沒影響(4.37 vs 4.20mm)。
4. **唯一乾淨的改善是讓兩片真的疊起來**(`--tip_over_mm 40`,尖端越過杯子中線 40mm)。原本兩片在中線對接、只重疊 20mm 寬,`layer_gap` 量到中位 **1 層**。越線之後中位 2 層,自穿模三段 2 / 55 / 144(基準 13 / 257 / 512),壓實放開後 133(基準 163)。
5. **壓實放開後的回彈 13~17mm 是折疊布的彈性**(`restBendAnglesDefault = flatDefault`,每道折都想回平),所有變體壓到 117 都彈回 130~134。要解得靠摺痕定型(`omniphysics:restBendAngles` 逐邊陣列 runtime 寫入,探針中)或讓箱蓋接手壓住。
6. **層間距卡在 4.2~4.4mm**,跟 thick / 放手 / offset 都無關。真實泡泡紙一層 3~4mm,這個值接近實物;唯一還沒排除的是網格解析度(35×35、每格 17mm,皺褶波幅)。
7. **入箱段從來沒有真正跑過**:`--carton carton_w131.usd` 找不到 `carton_w131.meta.json` → `LIDS` 空、蓋子沒動、階段名照印。補 meta 之後定版紙箱的蓋子方向與 `lid_pose()` 假設相反(USD 預設姿態是關),t=0 就把包裹壓扁;入箱時杯子的平移也被多算一次 (−8.7, −5.5) mm。修正中。

## 3. 今天加進 `wrap_sim.py` 的旗標(預設全部 = 舊行為;原檔 `wrap_sim.py.orig_20260930`)
| 旗標 | 意義 | 建議值 |
|---|---|---|
| `--tip_over_mm` | 折邊尖端越過杯子中線多少 mm | **40** |
| `--release_after` | 每一折拉到位幾秒後放掉錨點(刪 attachment Scope + 方塊 prim)| 0.3(第二段要配合保留 hold)|
| `--no_hold` | 第二段不建 100 個 hold 錨 | **不要用**(bend 4 會讓折邊翻回去)|
| `--no_anchor` | 完全不建錨(壓實 / 入箱段用)| 壓實段必開 |
| `--hold_mm` | 尖端終點離杯頂 mm(原寫死 12)| ≥ thick + 2mm |
| `--cont` / `--rest` | 布 collider 偏移量(原寫死 5 / 1 mm)| **維持 5 / 1** |
| `--self_filter` `--pair_freq` `--col_iter_mult` `--ccd` | 自碰撞細參數 | 沒有幫助 |
| `--no_sleepy` | 關 sleep(既有旗標)| 量回彈時必開,否則布睡著掩蓋 14mm |
