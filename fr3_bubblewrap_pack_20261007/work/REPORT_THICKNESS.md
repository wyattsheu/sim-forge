# 包起來的厚度與體積合不合理 —— 簡報(2026-10-02)

杯子躺平 bbox **107 × 133 × 93 mm**。所有數字來自 `work/` 實跑,工具 `layer_gap.py`(杯頂上方數層、量間距)。

## 1. 結論

**不合理,而且主要不是高度,是寬度。**

| | 目前最佳(u 鏈,蓋子壓住後) | 杯子 | 多出來 |
|---|---|---|---|
| 高 z | 125 | 93 | **+32**(頂 26 + 底 ~5)|
| 寬 x | 232 | 107 | **+63 / 側** |
| 深 y | 213 | 133 | +40 / 側 |
| 體積 | 6.2 L | 1.3 L | **4.7 倍** |

真實泡泡紙包一個杯子,體積約 1.5~2 倍。現在是 4.7 倍。

## 2. 高度:93 → 125,這 32mm 是什麼

杯頂上方疊了 **4~5 層**布(四折各一片、尖端越線重疊),每層隔 **4.3~5.6 mm**。

- 第 1 層離杯頂 4.7mm
- 層與層 5.6mm(壓住時 4.0,放開彈回)
- 底下墊著 1 層 ~5mm

93 + 4.7 + 3×5.6 + 5 ≈ 120,量到 125。算式對得上。

**「包起來應該小於 100」要成立,每層得 < 1.5mm。** 這是材料問題:

| 材料 | 一層實際厚度 | 杯子 + 4 層頂 + 1 層底 |
|---|---|---|
| 泡泡紙(小泡)| 3~4 mm | **108~113** |
| 泡泡紙(大泡)| 8~10 mm | 133~143 |
| PE 薄膜 / 保鮮膜 | 0.05~0.5 mm | 93~96 |

交接文件寫的是**泡泡紙**。模擬量到的 4.3~5.6mm/層,在小泡泡紙的範圍上緣,**高度這部分不算離譜**,離「<100」差的是材料種類不是模擬錯。

模擬裡這個 4.3mm 的來源是布對布的自碰撞靜止距離,今天驗過:
- 不是彎曲彈性(把靜止形狀設成壓扁的,照樣彈回 134)
- 不是 surfaceThickness(10 → 4mm 沒變)
- 不是網格太粗(34 → 50 反而變 6.6)
- restOffset 1 → 0.2 能壓到 4.0,但布層互穿(自穿模 ×2)

要模擬薄膜,就要接受 restOffset ≈ 0.2 這組參數再去解互穿,那是另一條路。

## 3. 寬度:107 → 232,這 63mm/側 才是大頭

布是 **586 × 586 mm** 的正方形。包一個 107×133×93 的東西,理論最小約 (133+2×93+重疊) × (107+2×93+重疊) ≈ **350 × 320**。586 是腳本按「佔位塊 131×157×105 + 爬升 105 + 橫過 79 + 重疊 25」算的,每邊折邊長 195~208mm,**比杯子高度 93 多一倍**。折上去蓋住頂面之後,多出來的 100mm 布沒地方去,堆在四個側面,壓實也只是把它壓成 63mm 厚的側墊。

壓實目標 `--press6 250,210,115` 是照紙箱內腔(264×224)訂的,不是照杯子訂的,所以壓板停在 250×210 就不壓了。

## 4. 建議(照投入成本排)

1. **布縮小**:`--sheet_mm 400`(或讓 `--margin` / `--overlap` 縮)跑一次,看寬度能不能到 ~150、體積到 2 倍。這是最便宜的一步,一段模擬 3 分鐘。
2. **壓實目標照杯子訂**:`--press6 150,170,110` 之類,讓側面真的被壓。要同時看自穿模。
3. **材料口徑先講清楚**:demo 的包材是泡泡紙就接受 110~125 的高度;要「<100」就改成薄膜物理,得重做 restOffset / 自穿模那組實驗。
4. 高度上蓋子已經能把 134 壓到 125 並關上,布/杯超出內腔 0 —— 入箱這件事現在是成立的。
