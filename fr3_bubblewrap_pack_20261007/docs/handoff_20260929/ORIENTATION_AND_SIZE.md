## 1. 世界座標與「前後左右」

```
        +z 上
         │
         │      +y 前
         │     ╱
         │   ╱
         └────────── +x 右
```

| 方向 | 軸 |
|---|---|
| 前 | **+y** |
| 後 | −y |
| 右 | **+x** |
| 左 | −x |
| 上 | +z |

「前後左右」一律指**箱子自己的座標**。包材的折法、杯子的姿態都吃這一組,不是各自定義。

## 2. 紙箱尺寸(定版)

```
外徑   270 (x) × 230 (y) × 131 (z) mm
板厚   3 mm(半厚 t = 1.5)
內腔   264 (x) × 224 (y) × 131 (z) mm
```

**長邊 270 沿 x**,也就是長邊落在**左右**方向。

> ⚠ `verify/SPEC.md` §3.1 寫著「箱子長邊平行 y」—— **那條是過期的**。
> 定版 USD 實際是 hx=0.1335(x 外徑 270)、hy=0.1135(y 外徑 230)。
> §4c 也記著「hx/hy 對調」試過並回退(下蓋長度 115 是相對長邊量的,對調後縫隙算出 −6mm)。
> 以本檔與 meta.json 為準。

### 四片蓋

| | 位置 | 層 | 深度/長度 | 鉸鏈 z | 備註 |
|---|---|---|---|---|---|
| 上蓋 ×2 | ±y(**前/後**) | **外層** | 110.5 mm | 129.5 mm | 兩側與箱壁齊邊,每邊留 1 mm |
| 下蓋 ×2 | ±x(**左/右**) | **內層** | 115 mm | 123 mm | 兩片之間**縫隙 34 mm**(真實 RSC 內側短翼不對接) |

### 箱壁高度(不是齊平的,刻意的)

```
±x 牆頂 = 120.0 mm   (= 下鉸鏈 123 − 2t)
±y 牆頂 = 126.5 mm   (= 上鉸鏈 129.5 − 2t)
```

理由:鉸鏈在箱壁內面、蓋子是 3mm 厚的板,蓋子一傾斜外上角就掃進箱壁那條帶子。
牆頂不降的話 0~180° 之間有 360/361 個角度重疊。降到「該面鉸鏈 − 2t」之後是 0/361。
用 `scripts/carton_sweep.py` 可重驗,它還有 `--selftest` 會把牆頂改回箱口高度證明自己抓得到缺陷。

### 物理

```
base = dynamic     ← 必須。PPT 成功定義:「箱子會隨著手臂運動而被移動,不能黏在桌面上」
```
不要從舊 meta.json 的 inputs 抄指令 —— 那裡面帶著當時的 `dynamic: False`。
要改尺寸就改 `carton/make_definitive.sh` 裡的變數,不要在別處另開一行指令。

## 3. 杯子方位

```
杯子橫放於箱子中央(PPT 成功定義)
杯口朝 前 (+y)
杯耳朝 右 (+x)
```

驗法:`scripts/selfcheck.py` 會檢查旋轉矩陣 det=+1(是純旋轉不是鏡像)
以及杯口/杯耳兩個向量轉完之後確實落在 +y / +x。

> 這一版(Sep 27)的包材腳本**沒有**杯子方位矩陣 `_Rm`,杯子方位尚未套用。見 §4。

## 4. 開箱順序與包材折序的關係(重要)

PPT 的動作序列:

```
左手按壓(固定)前方的紙箱耳朵 / 右手掀開後方的紙箱耳朵
左手按壓(固定)後方翻開的紙箱耳朵 / 右手掀開前方的紙箱耳朵     ← 前後(±y)先
右手固定紙箱的右下方 / 左手協助掀起右方的紙箱耳朵
左手固定紙箱的左下方 / 右手協助掀起左方的紙箱耳朵              ← 左右(±x)後
不限定左右手將泡跑紙上下方打開
左手開啟左邊泡泡紙 / 右手開啟右邊泡泡紙
右手夾取馬克杯耳朵,並垂直放置於桌上
```

**先開的一定是外層。** 紙箱這邊已經對上了:上蓋在 ±y(前後)= 外層,先開;下蓋在 ±x(左右)= 內層,後開。

**包材這邊沒有對上。** 本包附的是 Sep 27 版包材,它是**先折 y、x 在外層**,
所以逆向開起來會變成「左右先開」,與 PPT 相反。這是已知缺陷,見 `TASK_INTERN.md` §已知問題。
